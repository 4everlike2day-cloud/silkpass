# Бот @w2uz_bot «Узбекистан: что посмотреть»

Бот показывает места из таблицы «Узбекистан: что посмотреть» по категориям. Под каждым местом кнопки 👍 / 👎.
Один голос на аккаунт Telegram, повторное нажатие той же кнопки снимает голос. Голоса пишутся на лист «Голоса»,
счётчики — в столбцы «Лайки» и «Дизлайки» листа «Места». Пока места в статусе «Черновик», бот их показывает
(для проверки), сайт — только «Опубликовано».

Код: `web/functions/api/places-bot.ts` (вебхук) и `tools/places-apps-script.js` (скрипт таблицы).
Токен и пароли в репозиторий не кладём — только в Cloudflare и в свойства скрипта.

## Настройка (один раз)

1. **Скрипт таблицы.** Таблица → Расширения → Apps Script → вставить `tools/places-apps-script.js`.
   Настройки проекта → Свойства скрипта → `SECRET` = длинный пароль.
   Развернуть как веб-приложение: от имени «Я», доступ «Все». Скопировать URL `…/exec`.
2. **Cloudflare Pages: переменные.**
   1. dash.cloudflare.com → в левом меню **Compute (Workers)** → **Workers & Pages** (в некоторых аккаунтах сразу **Workers & Pages**).
   2. Выбрать проект сайта welcome2.uz → вкладка **Settings** вверху.
   3. Переключатель окружения над настройками → **Production**.
   4. Блок **Variables and Secrets** (там уже есть `TELEGRAM_BOT_TOKEN`, `REGISTRY_URL`) → **+ Add**:
      - `PLACES_BOT_TOKEN` — Type **Secret**, значение: токен от BotFather
      - `PLACES_SCRIPT_URL` — Type **Text**, значение: URL из шага 1 (`…/exec`)
      - `PLACES_SECRET` — Type **Secret**, тот же пароль, что `SECRET` в скрипте
      - `PLACES_WEBHOOK_SECRET` — Type **Secret**, новый пароль, только латиница и цифры
   5. **Save** (или **Deploy**) внизу блока.
   6. Переменные применяются к следующей публикации: запушить код и дождаться во вкладке **Deployments** новой строки со статусом **Success**.
3. **Вебхук.** Открыть в браузере одну ссылку, подставив токен и `PLACES_WEBHOOK_SECRET`:
   `https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://welcome2.uz/api/places-bot&secret_token=<PLACES_WEBHOOK_SECRET>&allowed_updates=["message","callback_query"]`
   Ответ должен быть `"ok":true`.
4. **Команды в меню** (необязательно): BotFather → `/setcommands` → @w2uz_bot →
   ```
   start - Места по категориям
   site - Все места и рейтинг на сайте
   ```

## Проверка
Написать боту `/start`, открыть категорию, нажать 👍 — в таблице на листе «Голоса» появится строка,
у места в «Лайки» станет 1. Список мест бот обновляет раз в минуту.

## Канал (потом)
Добавить @w2uz_bot администратором канала — и можно публиковать места постами с теми же кнопками.
Голоса привязаны к ID места, набранные в личке сохранятся.

## Если бот не отвечает
1. Открыть `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo` и посмотреть `last_error_message`.
   - `403 Forbidden` — пароль в `setWebhook` не совпадает с `PLACES_WEBHOOK_SECRET`. Записать новый пароль
     (только латиница и цифры) в Cloudflare, перевыложить сайт, заново открыть ссылку `setWebhook`.
   - `500` — в Cloudflare не хватает переменных `PLACES_…` или сайт не перевыложен после их добавления.
2. Если бот пишет «⚠️ Бот не смог ответить: таблица ответила не JSON … accounts.google.com» —
   у веб-приложения Apps Script доступ не «Все». Расширения → Apps Script → Начать развёртывание →
   Управление развёртываниями → карандаш → «У кого есть доступ: Все» → Версия «Новая» → Развернуть.
3. «Не получилось сохранить голос» — `SECRET` в свойствах скрипта не совпадает с `PLACES_SECRET` в Cloudflare.
4. Перевыложить сайт без изменений кода: GitHub → Actions → верхний запуск → Re-run all jobs.

## Фото мест
Столбец «Фото» — прямая ссылка на картинку (.jpg/.png), которую Telegram может скачать.
Не подходят ссылки на пост в Instagram и страницы Google Диска.
Надёжнее всего: положить файл в `web/public/places/` с именем по ID (`T001.jpg`), запушить
и вставить в таблицу `https://welcome2.uz/places/T001.jpg`.
Если картинка не скачалась, бот покажет место без фото.
